# Fuzzy MCDM for Sustainable Highway Restaurant Site Selection

**An Excel-based academic project on fuzzy multi-criteria decision-making, comparative ranking methods, and sensitivity analysis.**

## Project Overview

This academic project focuses on the application of fuzzy Multi-Criteria Decision-Making (MCDM) methods to sustainable highway restaurant site selection.

The project reproduces a published fuzzy AHP–TOPSIS framework using Microsoft Excel and extends the analysis through consistency evaluation, comparative ranking methods, and sensitivity analysis.

The objective is to examine the application of fuzzy decision-making techniques to location selection problems and investigate the robustness of alternative rankings.

## Project Objectives

- Reproduce the published fuzzy AHP–TOPSIS framework in Microsoft Excel.
- Examine the consistency of pairwise comparisons and revise inconsistent inputs.
- Evaluate and rank alternative highway restaurant locations.
- Compare rankings obtained using TOPSIS, VIKOR, and Simple Additive Weighting (SAW).
- Perform sensitivity analysis to investigate the stability of the results.

## Methodology

### 1. Fuzzy Analytic Hierarchy Process (Fuzzy AHP)

Fuzzy AHP is used to determine the relative importance of evaluation criteria while accounting for uncertainty in pairwise comparisons.

The original framework was reproduced in Excel, and consistency issues were identified and investigated.

Revised pairwise comparison inputs were proposed, achieving a **consistency ratio (CR) of 0.0693**, below the commonly used threshold of 0.10.

### 2. TOPSIS

The Technique for Order Preference by Similarity to Ideal Solution (TOPSIS) is used to evaluate and rank alternative restaurant locations.

The ranking process considers the relative closeness of each alternative to the positive ideal and negative ideal solutions.

### 3. Comparative Analysis: VIKOR and SAW

Two additional MCDM methods were examined to compare the resulting rankings:

- **VIKOR:** A compromise-ranking method that considers group utility and individual regret.
- **SAW (Simple Additive Weighting):** An additive scoring method based on weighted evaluation criteria.

The rankings obtained from TOPSIS, VIKOR, and SAW were compared to investigate differences across decision-making approaches.

### 4. Sensitivity Analysis

Sensitivity analysis was conducted to examine how changes in model inputs and evaluation criteria affect the ranking of alternatives.

This analysis provides additional insight into the robustness of the decision-making results.

## Project Contributions

The project builds on the methodology of the original research paper rather than proposing a new fuzzy MCDM framework.

The main academic contributions include:

- Reproducing the published fuzzy AHP–TOPSIS methodology in Microsoft Excel.
- Identifying consistency issues in the pairwise comparison inputs.
- Proposing revised inputs and obtaining a consistency ratio of **0.0693**.
- Comparing alternative rankings using TOPSIS, VIKOR, and SAW.
- Performing sensitivity analysis to evaluate ranking robustness.
